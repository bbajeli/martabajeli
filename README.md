# Sito della Dott.ssa Marta Bajeli, Pediatra

Sito vetrina statico (HTML, CSS, JS). I font sono nella cartella `fonts/` (cormorant.ttf, cormorant-italic.ttf, jost.ttf), pronto per GitHub Pages.

## Pubblicazione
```
git init
git add .
git commit -m "Primo commit"
git branch -M main
git remote add origin https://github.com/<utente>/<repo>.git
git push -u origin main
```
Poi su GitHub: Settings → Pages → Branch `main`, cartella `/ (root)`.
